🆕 2026 年才高频的新题

1. Harness / Skill / MCP / Function Call

四个词的关系与区别。FC 是模型调工具的协议，MCP 是工具的标准接口，Skill 是可复用的能力包，Harness 是把这些串起来跑的工程层。

2. Agent 上下文管理

长对话怎么压缩、压缩怎么不丢关键信息、哪些算关键信息。这一组在小红书被连问了 8 层。

3. ReAct 能不能解决上下文问题

标准答案是「不能」：ReAct 解决的是下一步做什么，不解决历史太长。要能讲清它管什么、不管什么。

4. AI Coding / Vibe Coding 现场考

不是让你写代码，是看你能不能先把需求讲清楚再让 AI 写。小红书明确要求先提炼需求、再用 Codex。

5. AI Native vs AI Empowered

重做一个产品，还是在老产品上加 AI。要能说出各自的组织成本、数据条件、商业化路径。

6. 多 AI 功能的归因

几个 AI 功能共用一个入口，怎么算各自贡献、协同还是互斥。本质是实验设计和指标口径题。

7. 缓存命中率

「用户希望缓存命中尽可能高，你会怎么处理 Agent？」考的是上下文复用和前缀缓存的理解。

8. 评测体系（上线前 + 上线后）

离线基准集怎么建、人工标注怎么控一致性、线上灰度回滚、红队。还要能说怎么避免被单一指标骗。

9. 模型选型三角

大模型 / 小模型、要不要多模态、要不要精调，成本、延迟、效果怎么同时拉齐。

10. 推理 / 非推理模式切换

Qwen3 这类模型能在两种模式间切。要能说出什么场景该开思考、什么场景不该。

👀 面试官视角（2026.10.27 的真实帖子）

一位秋招面试官写的，比任何面经都直接：

  • 公司最看重的是潜力，拆成四项：学历、能力、性格、口头表达。综合测评不是走过场。
  • 简历要让面试官问得出问题。通篇写与岗位无关的技术栈，面试官只能考你八股，一考就露。
  • 「我在网页上用过、调过 API」不算了解。被问 DeepSeek，要能讲到模型结构层面。
  • 手撕和 vibe coding 两轮都可能考。有人刷过题库但没想法，二面照样挂。
  • 他透的题：Transformer 核心结构、Mamba 和 Transformer 的区别、Function Call、MCP 和 skills 的关系、Agent 缓存命中率。
