Prompt 工程

Prompt 是 AI PM 最直接的"生产工具":不写代码也能显著改变产品效果。进阶则要理解：线上效果往往取决于「窗口里拼进了什么」——见 Context Engineering。

目录

  • Prompt 基本功:角色、任务、约束、示例、输出格式(含 Few-shot 用法)
  • 结构化输出:让模型稳定吐出 JSON
  • 系统提示词设计与 Prompt 工程化:把玄学变工程(含版本管理与回归测试)
  • Context Engineering：从写 Prompt 到拼上下文系统 —— Prompt Eng vs Context Eng；缓存 / 工具上下文 / PM 边界
  • 思维链(CoT):让模型先想再答 —— 适用场景、成本权衡、Self-Consistency;面试题见 什么是思维链?
